# K1ND.world v4.10.0 changelog

Build: **Global Moderation Learning Product Preview**

V4.10.0 was created from an exact copy of V4.9.0. The V4.9 folder and packaged archive remain unchanged.

## Global language wave

- Added 60 functional rules across Arabic, Russian, Ukrainian, Mandarin Chinese, Japanese, Korean, Turkish, Greek, Romanian, Hungarian, Slovak, Serbian, Croatian and Bosnian.
- Expanded deterministic functional coverage from 15 to 29 languages, with Australian English and selected Punjabi-influenced Romanised variants retained as additional regional coverage.
- Added targeted personal degradation, aggressive dismissal, severe sexualised/family abuse, death-wish and carefully gated identity-hate functions for each new language group.
- Added 12 native-language dismissive rewrites.
- Added 86 new abusive and safe-context fixtures, including Latin, Arabic, Cyrillic, Greek, Han, Japanese and Hangul scripts.

## Governed learning loop

- Native-reviewed language candidates now create structured learning items awaiting regression.
- Audience probes promoted from the red-team recorder enter the same learning queue.
- Moderators can mark regression evidence as approved for the next pack, needing more evidence or rejected.
- Learning items never activate a browser rule. Deployment remains a reviewed, tested and versioned code change, preventing feedback poisoning and accidental censorship.

## Moderator workspace

- Active policy console expanded from 91 to **151** rules.
- Added a dedicated **Priority global wave** filter.
- Added learning-stage counters for native review, regression and next-pack approval.
- Raw high-impact fixtures remain redacted from presenter-facing test views.

## Verification

- Canonical moderation fixtures: **392/392**.
- Adversarial Hate Stress Test fixtures: **246/246**.
- Combined readiness: **638/638**.
- Expected hard blocks: **305/305**.
- Neutral and protected-context fixtures: **127/127**.
- Generated rewrites checked clean on re-moderation: **91/91**.
- JavaScript syntax validation, the complete automated moderation suite, live browser verification, the governed-learning workflow and the phone-size demo check all passed before packaging.

## Product boundary

The language rules and learning workflow are functional inside the browser preview. Production requires server-side enforcement, durable evidence and policy storage, native-language review operations, multilingual contextual models, dialect/code-mix evaluation, appeals, monitoring and independent adversarial testing.
