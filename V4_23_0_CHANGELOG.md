# K1ND.world V4.23.0 changelog

Release: **Live Audience Arena**

V4.23.0 was built from an exact copy of the preserved V4.22.0 Live Match Room & Personal Athlete Shield. V4.22.0 remains unchanged.

## Added

- A multi-device local Arena connecting an audience join screen, a protected athlete screen and a moderator-only presenter command view.
- Temporary eight-hour event passes, opaque signed cookies, a separate anti-forgery token and a 40-participant local demonstration cap.
- A local QR handoff and room code. QR rendering uses the included macOS Core Image helper and does not contact an external QR service.
- Server-sent events plus a timed polling safety net so fan, athlete and presenter views converge on the same server revision.
- Server-owned rate limits, duplicate suppression, slow mode and crowd-pressure-aware friction.
- A role-separated athlete payload containing only delivered content; non-clean originals are neither stored in the Arena transcript nor returned to athlete or presenter views.
- Accurate mixed-intent rewrite-and-retry through the active moderation engine, retaining the author's real sporting point.
- Human-owned Arena status, shield, digest and athlete-reply controls with an audit trail and no automatic account sanction.
- A deterministic six-message offline rehearsal running through the active server engine.
- Twenty-one new Arena and release checks, taking the authenticated black-box server suite to **109/109**.

## Demonstration proof

- `Fuck what a great shot` reaches the athlete unchanged as emphatic praise.
- Strong sporting criticism reaches the athlete unchanged.
- Mixed sporting criticism and personal degradation are separated; the hostile original stays outside the athlete view and the real sporting point can be resent.
- Credible threats are blocked before athlete delivery and no external message is sent.
- Presenter and athlete screens update from the same server-owned decision stream.
- Public Experience now lands in Arena Live while Arena Control remains behind moderator permission.

## Retained

- **882/882** browser moderation readiness, including **600/600** canonical checks.
- **180/180** generated severe-evasion gate with zero severe misses and zero protected neutral-control regressions.
- Live Match Room, Personal Athlete Shield, Event Safety Twin, Safety Intelligence, Event Command and governed learning.
- Session-scoped public mode and Shift+Escape presenter return.
- Human authorisation and explicit no-external-delivery boundaries.

## Honest boundary

The match, score, identities and rehearsal traffic are simulated. A temporary event pass is not production identity verification. The QR defaults to the local host; multiple phones require the presenter to opt into LAN binding on a trusted local network. Displayed latency is local demonstration timing, not a production service-level claim. No account sanction, governing-body notification, venue-security message or emergency action occurs automatically.
