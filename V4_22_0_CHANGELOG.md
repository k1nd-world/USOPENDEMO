# K1ND.world V4.22.0 changelog

Release: **Live Match Room & Personal Athlete Shield**

V4.22.0 was built from an exact copy of the preserved V4.21.0 Public Experience Curtain. V4.21.0 remains unchanged.

## Added

- A server-owned Live Match Room connecting a fan composer, an inspectable K1ND decision spine and a protected athlete inbox.
- A public **Match Live** route and a focused athlete second-screen mode at `/match-room?view=athlete`.
- Contextual profanity handling that delivers non-abusive emotional reactions such as `Fuck what a great shot`.
- Strong sporting-criticism preservation without forcing a rewrite.
- Accurate, source-backed rewrite-and-retry for mixed sporting criticism and personal abuse.
- A no-invention state when there is no genuine point to preserve.
- Personal Athlete Shield settings for protection level, digest timing and reply access.
- A crowd-pressure routing signal with visible inputs, friction state and a non-probability boundary.
- A wellbeing digest that reports withheld categories without revealing hostile originals.
- Ten new authenticated black-box contracts, taking the server contract suite to **88/88**.

## Strengthened

- The independent server semantic reasoner now promotes represented high-confidence person-directed attack clauses even when a narrower baseline pattern misses the grammar.
- Non-clean Match Room originals are replaced by category and evidence-digest metadata in the readable room transcript.
- Every accepted rewrite is rechecked by the independent server before athlete delivery.
- Threats retain the severe-harm floor and cannot reach the athlete inbox.
- **View as user** now opens Match Live, making the public product experience the centre of the demonstration.

## Retained

- **882/882** combined browser readiness, including **600/600** canonical moderation checks.
- **180/180** generated severe-evasion release gate with zero severe misses and zero protected neutral-control regressions.
- Live Athlete Shield, Event Safety Twin, Safety Intelligence, Event Command and governed learning.
- Session-scoped public mode and Shift+Escape presenter return.
- Human authorisation and explicit no-external-delivery boundaries.

## Honest boundary

The match, score, accounts and traffic are simulated. The moderation decisions use the active local K1ND server engine. The crowd-pressure score is an explainable routing heuristic, not a probability. No account sanction, governing-body notification, venue-security message or emergency action occurs automatically.
