# K1ND.world v4.16.0 changelog

V4.16.0 is the **Production Pilot and Adaptive Safety Preview**, built from an exact preserved copy of V4.15.0.

## Added

- Cross-thread campaign intelligence for repeat targeting, pile-ons and post-match abuse bursts.
- Critical safeguarding incidents with priority-based SLAs and response plans.
- Automatic preparation of a WTA/ATP/tournament-security packet for credible tennis threats.
- Human disclosure authorisation with an explicit `approved_not_sent` state when no secure connector exists.
- Evidence-minimised partner packets containing structured context, receipt references and a digest rather than routine raw content.
- Protected 20-case curated server calibration with exact outcome, precision, recall and false-positive reporting.
- Governed language/context learning through native review, regression, shadow observation and next-release approval.
- Model/provider ensemble status separating active enforcement, escalation-only, advisory, unconfigured and staffing-dependent capability.
- A new authenticated `/pilot-ops` moderator workspace.

## Explicit boundary

No external WTA, ATP, tournament-security, emergency-services or law-enforcement connector is configured. V4.16 prepares and authorises a local packet but cannot claim delivery. Production use requires contracts, named endpoints, a lawful disclosure protocol, a restricted encrypted evidence vault, monitoring and trained safeguarding cover.
