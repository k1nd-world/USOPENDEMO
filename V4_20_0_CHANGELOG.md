# K1ND.world V4.20.0 changelog

Release: **Live Athlete Shield & Event Safety Twin**

V4.20.0 was created from an exact copy of V4.19.0. The preserved V4.19.0 source folder and archive were not changed.

## Added

- Moderator-only `/athlete-shield` product surface.
- Deterministic 24-message simulated match-point burst evaluated by the live K1ND server engine.
- Fifteen language variants and four scripts in the event scenario.
- Live allow/intervene/review/block stream with category, speech act, target and harm-mechanism evidence.
- Redacted evidence digests for every non-clean message; raw hostile wording is never returned by the Event Safety Twin API.
- “Without K1ND / With Athlete Shield” exposure comparison and protected inbox.
- Cross-account, cross-thread and cross-language campaign-candidate graph.
- Clearly labelled simulated image-OCR signal fused with text and context.
- Incident replay timeline.
- Moderator Copilot recommendations with `actionApplied: false` and no autonomous emergency action.
- Human-set slow mode, new-account friction, enhanced language review, reply-burst limit and demo lockdown controls.
- Metadata-only threat packet requiring human authorisation.
- Explicit connector state and `externalMessageSent: false` before and after local authorisation.
- Four authenticated APIs for run, reset, controls and escalation authorisation plus a protected summary API.
- Ten new black-box contracts, bringing the authenticated server suite to 78/78.

## Retained

- V4.19 Semantic Context & Intent Engine and ten-stage explanation path.
- Contextual profanity handling: praise, sporting emphasis and reported language remain clean.
- Clause-level mixed-intent reasoning and source-faithful rewrite behavior.
- Non-downgradable severe-harm floor.
- 600/600 canonical, 262/262 stress, 20/20 multimodal and 882/882 combined browser readiness.
- 180/180 generated severe-evasion release gate and 23/23 curated server calibration.

## Boundaries

- The event, accounts, traffic and OCR signal are simulated.
- Social-network ingestion is not connected.
- WTA, ATP, venue-security, emergency-service and law-enforcement delivery are not connected.
- The graph score is a routing heuristic, not probability, attribution or guilt.
- Moderator Copilot recommends only; trained human verification remains required.
- This release does not claim universal, human-superior or production-ready moderation.
