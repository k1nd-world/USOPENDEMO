# K1ND.world V4.21.0 changelog

Release: **Public Experience Curtain**

V4.21.0 was created from an exact copy of V4.20.0. The preserved V4.20.0 source folder and archive were not changed.

## Added

- One-click **View as user** control for the authenticated presenter.
- A session-scoped public experience that persists across navigation and refresh in the active browser tab.
- Public navigation limited to Home, Feed, Create, Profile, Appeals and About.
- Internal-route guard covering Demo Lab, Media Lab, Stress Test, Control Room, Admin, Pilot Ops, Event Command, Safety Intelligence, Athlete Shield and the legacy athlete demo page.
- Discreet Shift+Escape presenter return.
- Public-facing variants for Home, Feed, Profile, public profiles, Verification and About.
- Public reporting language that refers to the safety team rather than an admin queue.
- Public profile treatment that hides role labels, simulated verification references, trust scores and internal moderation metrics.

## Retained

- Complete V4.20 Live Athlete Shield and Event Safety Twin.
- Server-authoritative moderation, authenticated publication, signed receipts and durable local evidence.
- 600 canonical, 262 adversarial, 20 multimodal and 882 combined browser checks.
- 78 authenticated black-box server contracts.
- Contextual profanity behavior, including clean emphatic praise such as `Fuck what a great shot`.

## Boundaries

- Public Experience is a presentation curtain, not an access-control substitute for a production deployment.
- Demo accounts and local data remain underneath the public-facing experience.
- Presenter restoration is intentionally keyboard-only while the curtain is active.
- Production use still requires separate managed user and operational deployments, strong authorization, managed identity and independent assurance.
