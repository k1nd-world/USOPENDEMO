# K1ND.world v4.11.0 changelog

## Universal direction

- Added 50 inspectable moderation rules and 70 paired fixtures across ten language groups: Bengali plus Romanised Bengali, Persian/Farsi, Hebrew, Indonesian, Malay, Vietnamese, Thai, Tagalog/Filipino, Swahili and Amharic.
- Expanded active deterministic coverage from 29 to 39 functional language groups and from 151 to 201 versioned rules.
- Added Bengali, Thai and Ethiopic-script recognition and retained combining marks during normalization.
- Added native-language boundary-setting rewrites for recoverable dismissive commands.
- Added target-gated degradation and dehumanisation, severe-abuse and death-wish outcomes, plus educational, translation, research and literal-use exemptions.

## Rewrite fidelity

- Replaced generic fallback rewrites with source-clause extraction and abusive-span removal.
- Added `sourceBasis`, `fidelity`, `transformation`, `preservedPoint` and `removed` rewrite evidence.
- Preserved the actual sporting or discussion proposition and its critical stance where possible.
- Qualified unverified integrity, cheating and doping allegations.
- Added `safeDraftSuggestion` for the narrow case where a hard-block original contains a separable clean proposition.
- Kept `rewriteSuggestion` undefined for every hard block, so the original never acquires a publication bypass.
- Re-moderated every offered rewrite and safe draft before exposing it.
- Continued to offer no automatic text when the draft has no legitimate proposition.

## Product and demonstration

- Updated feed interventions to distinguish source-backed rewrites from separately validated new drafts.
- Added rewrite source/fidelity evidence to Demo Lab and Hate Stress Test.
- Added accurate-rewrite and hard-block-plus-clean-point challenge samples.
- Updated Admin with a Next language wave filter and all 50 added rules.
- Updated landing, rehearsal, About and product-boundary copy.
- Isolated V4.11 module and local-state cache namespaces from previous builds.

## Verification

- 473/473 canonical moderation fixtures pass.
- 246/246 adversarial Hate Stress Test fixtures pass.
- 719/719 combined checks pass.
- 328 expected hard blocks remain non-bypassable.
- 147 expected clean/contextual fixtures remain clean.
- 108/108 warning/review rewrites re-moderate clean.
- 3/3 separately offered hard-block safe drafts re-moderate clean.
- All JavaScript modules pass syntax validation.

## Boundary

This remains a deterministic product preview. It demonstrates a reviewable moderation and rewrite contract; it does not claim universal language understanding or production-grade detection. Production still requires secure server enforcement, maintained multilingual models, native reviewers, monitoring, appeals and per-language/community evaluation.
